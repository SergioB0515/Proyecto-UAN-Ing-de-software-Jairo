# src/views/

Una vista por pantalla principal, alineadas con las épicas de
[06. Historias de usuario](../../../documentacion/06-historias-usuario.md):

- `LoginView.vue`
- `ContribuyentesView.vue` (listado y alta de contribuyentes)
- `PatrimonioView.vue` (activos y fuentes de ingreso de un contribuyente)
- `ImportarExogenaView.vue` (carga del archivo Excel de la DIAN)
- `ConciliacionView.vue` (resultado de la conciliación)
- `InventarioView.vue` (categorías, productos, movimientos — oculta si el
  contribuyente es `ASALARIADO`)
- `ReportesView.vue` (cierre de periodo y descarga de reportes)
