# src/components/

Componentes reutilizables entre vistas: tablas con filtros (para el
listado de `RegistroExogena` y el resultado de conciliación), formularios,
selector de contribuyente activo, y el indicador visual de estado
(`COINCIDE` / `DISCREPANCIA` / `NO_DECLARADO` / `NO_REPORTADO_POR_TERCERO`).
