# core/

- `seguridad.py`: hash argon2 y tokens JWT.
- `dependencias.py`: `obtener_contador_actual`, dependencia de cada router protegido.
- `excepciones.py`: errores de dominio; cada router los traduce a HTTP.
- `formato.py`: pesos con punto de miles para mensajes.
- `config.py`: variables de entorno.
